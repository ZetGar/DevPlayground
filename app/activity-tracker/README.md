# 📊 Activity Tracker (Part 1)

## 🧠 프로젝트 소개

사용자 행동 이벤트를 수집하고,  
이를 기반으로 사용자 상태를 계산하여 시각화하는 대시보드 시스템입니다.

이벤트 데이터를 단순 저장하는 것이 아니라,  
**사용자의 현재 상태를 정의하고 해석하는 것**에 초점을 맞췄습니다.

---

## 🎯 주요 기능

- 사용자 이벤트 생성 (click, login)
- 이벤트 기반 사용자 상태 자동 계산
- 시간 감쇠(decay)를 적용한 score 시스템
- 사용자 상태 대시보드 (Active / Idle / Churn)
- 실시간 데이터 갱신 (Polling)
- 필터 및 정렬 기능
- 커스텀 Select UI 컴포넌트

---

## 🔄 데이터 흐름

1. 사용자 이벤트 발생
2. 이벤트에 가중치(weight) 적용
3. 시간 감쇠(decay) 반영
4. score 계산
5. score 기반 상태 분류
6. Dashboard에 시각화
