# 📬 Behavior CRM System (Part 2)

## 🧠 프로젝트 개요

사용자 행동 데이터를 기반으로
이탈 위험을 감지하고 자동화된 액션을 실행하는 CRM 시스템입니다.

Activity Tracker에서 계산된 사용자 상태를 활용하여
조건 기반 자동화 흐름을 구현하는 것을 목표로 합니다.

---

## 🎯 목표

* 사용자 상태 기반 세그먼트 생성
* 조건 기반 트리거 시스템
* 자동화된 액션 실행 (메시지, 알림 등)
* 실행 결과 추적 및 분석

---

## 🔗 Activity Tracker와의 연결

Event → State → Segment → Action → Result

---

## 🧩 예정 기능

* 세그먼트 생성 (조건 기반)
* 트리거 시스템 (상태 변화 감지)
* 액션 시스템 (메시지, 알림)
* 캠페인 빌더 UI
* 실행 로그

---

## 💡 설계 방향

* 이벤트 기반 아키텍처
* 상태 기반 자동화 시스템
* 확장 가능한 구조
