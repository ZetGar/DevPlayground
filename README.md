# 🧠 User Behavior System (Portfolio Project)

## 📌 소개

사용자 이벤트 데이터를 기반으로  
상태를 계산하고 행동을 분석하여  
추천 액션 및 자동화로 확장 가능한 시스템입니다.

단순 CRUD가 아닌,  
**Event → State → Analytics → Action** 흐름을 중심으로 설계했습니다.

---

## 💡 프로젝트 배경

이전 회사에서 마케팅 및 기획팀과 협업하며  
사용자의 클릭, 로그인 등의 행동 데이터를 수집하는 기능을 개발한 경험이 있습니다.

당시에는 이벤트 수집까지는 구현했지만,  
그 데이터를 기반으로 사용자 상태를 분석하거나  
실제 액션으로 연결하는 시스템까지는 확장하지 못했습니다.

이 프로젝트는 그 경험을 바탕으로,

- 이벤트 데이터를 기반으로 사용자 상태를 계산하고
- 분석 결과를 통해 추천 및 자동화로 확장 가능한 구조를 설계하는 것을 목표로 했습니다.

---

## 🎯 핵심 흐름

Event → State → Analytics → Action

---

## 🧩 프로젝트 구성

### 1️⃣ Activity Tracker (Part 1)

- 이벤트 수집 (click, login)
- 사용자 상태 계산 (Active / Idle / Churn)
- 대시보드 시각화

👉 `/activity-tracker`

---

### 2️⃣ Behavior CRM (Part 2)

- 사용자 세그먼트 관리
- 자동화 트리거 (예: 이탈 사용자 알림)
- 캠페인 실행 시스템

👉 `/crm-system` (예정)

---

## ⚙️ 설계 포인트

- **Domain 로직 분리**
- **확장 가능한 구조 설계**

## 🚀 향후 확장
